02 / CONTROL SURFACE

The sliders.

Quick visual orientation for the controls documented throughout the guide. Values shown are conceptual examples, not claims that a slider has a universal optimal setting.

WEIRDNESS

Lower values generally favor a more constrained result; higher values can increase variation. Test rather than assuming deterministic behavior.

STYLE INFLUENCE

Controls how strongly the style direction participates in the result. Strong settings can still produce unexpected interpretation.

AUDIO INFLUENCE

Use deliberately when reference audio matters. The guide documents practical testing and audio-quality failure modes.
