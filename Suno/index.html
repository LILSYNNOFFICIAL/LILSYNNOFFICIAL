DIAGNOSE BEFORE REGENERATING

V6 audio problems.

01 / BAD MASTER

Crunch / clipping / artifacts

Run the rescue setup above before changing the creative identity. Compare the result against the source at matched loudness.

02 / VOCAL LOSS

Voice changed

Keep the entire source selected and keep the preservation language explicit. Avoid adding unrelated style instructions during the diagnostic pass.

03 / INSTRUMENT DRIFT

Arrangement changed

Use the exact performance-and-arrangement preservation language rather than asking for a new production.

04 / OVERPROCESSING

Muddy / crushed / phasey

Do not stack extra processing directions onto the rescue test. First establish whether the controlled setup produces a cleaner reference.

05 / A/B TEST

Compare fairly

Change one variable at a time. Keep the source, lyrics, model and influence values fixed while evaluating the audio.

06 / FAILURE BOUNDARY

Know what failed

If the same defect persists, classify whether the problem is the source, generation, mastering behavior or a localized section before escalating to editing/stems/Studio.
