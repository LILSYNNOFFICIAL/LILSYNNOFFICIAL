## 🔬 Experimental Method

The knowledge base documents experiments involving:

- Prompt density and minimalism
- Lyrics geometry
- Structure tags
- Symbols and gibberish
- Whitespace
- Punctuation
- Capitalization
- Randomness / variety / weirdness
- V6 / V6-WILD / V6-MINI comparisons
- Reference audio
- Edit versus regenerate
- Chorus consistency
- Failure-first testing

Experimental observations are not automatically treated as deterministic commands.

Record meaningful tests with:

```text
MODEL
INPUT
VARIABLE CHANGED
CONTROL
TEST
GENERATION COUNT
OBSERVATION
FAILURE MODE
RESULT
CONFIDENCE
EVIDENCE TYPE
```
