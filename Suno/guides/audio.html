Reference thinking

References are starting information, not a promise of literal copying. Give detailed guidance about what you want preserved or transformed.

Upload strategy

Use a clean, representative source when the source itself is important. If the reference contains irrelevant material, isolate the useful part before building around it.

V6 AUDIO QUALITY ISSUES

Mini V6 audio-quality rescue test

When Mini V6 produces unexpectedly degraded audio from a strong reference, treat this as a controlled diagnostic recipe rather than assuming the source track is bad. The following configuration is a reported working setup for recovering a cleaner, more reference-like result from a full-track Sample reference.

  • Model: Mini V6
  • Lyrics box: paste the exact test prompt below inside [ ] SND.
  • Style box: paste the same test prompt into the Styles box.
  • Weirdness: 0%
  • Style & Audio Influence: 86%
  • Other options: nothing else enabled
  • Sample: select the WHOLE TRACK

Exact test prompt

recreate the original audio exactly as sung and performed, identical vocal timbre phrasing dynamics intensity and emotion, identical instrument playing style technique feel and arrangement, identical overall musical energy and mood, ultra-professional studio mastering, lossless hi-fi, reference-grade mix, 24-bit digital clean, dynamic range 12dB+, wide cinematic stereo imaging, crystal-clear highs, high quality bass, perfectly balanced mids, zero mud, zero muddiness, zero low-end buildup, zero artifacts, zero compression artifacts, zero digital hiss, zero clipping, no frequency pollution, no resonance, no phase issues, fully transparent final master, radio broadcast quality, concert hall clarity, warm analog depth + razor-sharp digital precision, present lead vocals, wide and airy soundstage, high-fidelity studio production, crisp transients, layered instruments with clear separation, stable tonal balance and loudness

What this test is diagnosing

This is specifically a V6 audio-quality diagnostic. Compare the result against the original reference for vocal identity, transient clarity, stereo stability, bass cleanliness, midrange congestion, high-frequency artifacts, clipping/distortion, phase behavior, and overall loudness. Do not treat the descriptive mastering language as a guarantee that Suno will literally output a 24-bit master, 12 dB of dynamic range, or any other exact engineering specification; use those phrases as target characteristics and judge the rendered audio itself.

Controlled-test rule

Keep the configuration fixed while comparing results. If the recipe improves the audio, change one variable at a time in the next test. Save the successful configuration as a reproducible baseline.

Source quality vs. generation quality

A clean source can still produce a poor Mini V6 generation. If the source is clean but the generated result has mud, harshness, clipping, phase instability, smeared transients, or other artifacts, record it as a generation/audio-quality failure, not automatically as a source-file problem. Conversely, if the source itself contains those defects, do not expect prompt wording alone to restore information absent from the input.
