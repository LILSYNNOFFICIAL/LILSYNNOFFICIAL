Effects & Plugins

Shape tracks in real time with Studio's built-in effects and custom plugins created inside the Studio environment.

PRODUCEFXSTUDIO

Built-in processing

Studio 2.0 includes Compressor, EQ, Reverb, Convolution, Delay, Distortion and Gate. Effects run in ordered chains, so order matters.

Custom plugins

You can describe an effect to Studio's chat bar and have it build a custom effect for your library. These are Studio-native plugins; conventional VST and Audio Unit formats are not supported.

Chain discipline

LISTEN → BYPASS → CHANGE ONE PARAMETER → COMPARE → AUTOMATE → SAVE
