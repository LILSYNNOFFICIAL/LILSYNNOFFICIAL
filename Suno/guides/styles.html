Style Construction

Build a coherent sonic identity from genre, voice, instruments, groove, arrangement, dynamics, atmosphere and mix behavior.

CREATESTYLEARRANGEMENT

Master template

Primary identity: genre + subgenre
Vocal: register + texture + delivery
Core instruments: 3–7 important voices
Rhythm: groove + drum character
Arrangement: density and section arc
Dynamics: growth, peak and release
Atmosphere: emotional environment
Mix: vocal position + width + low end
Master: open + controlled + polished

Avoid prompt soup

One primary identity plus a small number of compatible influences is usually easier to control than ten unrelated genres. Describe what the listener should hear rather than what the prompt should “feel like.”
