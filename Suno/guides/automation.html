Make the mix move. Draw volume, pan and effect parameters over time, or use MIDI Learn with compatible hardware.

PRODUCEMOTIONMIDI LEARN

Automation targets

Studio 2.0 supports automation for track controls and plugin parameters. Automation is most useful when a static mix is technically correct but emotionally flat.

Arrangement examples

  • Volume lift into a chorus.
  • Pan movement for a transition.
  • Filter or effect changes that track an arrangement event.
  • MIDI Learn for hands-on control from compatible hardware.
