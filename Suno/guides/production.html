Don't polish the wrong problem

If the chorus is structurally weak, EQ will not fix it. If the vocal performance is wrong, mastering will not fix it. Diagnose the layer first.

QC

Check timing, clipping, vocal intelligibility, low-end translation, section transitions, fades, file format and metadata before release.
