Failure Diagnostics

Name the actual failure before changing the prompt. Controlled diagnosis beats random regeneration.

FIXTESTINGRESCUE

Diagnostic tree

BAD SONG?
├─ identity wrong → model / style
├─ words wrong → lyrics / section direction
├─ performance wrong → vocal / voice
├─ arrangement wrong → edit / extend / replace
├─ mix wrong → stems / Studio
└─ export wrong → format / QC

Controlled testing

Change one meaningful variable at a time. Keep a small test log: input, model, control state, result and what changed.

Rescue rule

Preserve any good section, take lane, vocal or stem before attempting a broader reconstruction.
