SEPTEMBER 2026 CURRENT REFERENCE

Last verified: September 17, 2026. This is the current product baseline. When older material conflicts with this section, this section wins.

01 / V6 MODEL FAMILY

  • v6: core model for general creation, control and refinement.
  • v6-wild: more experimental and less predictable, intended for discovery and variation.
  • v6-mini: lighter/faster model for quick iteration and high-volume exploration; available to all plans.
  • v6 and v6-wild: currently available to Pro and Premier subscribers.
  • All three current v6 variants support up to 8 minutes per generation.
  • Older generation models are retired for new iterations. Existing older songs remain in the library and can still be worked with through supported current workflows.

02 / CREATION

Current v6 supports richer direction than a traditional text prompt. Suno documents creation from text, audio, images and video, plus references to Suno songs/playlists and multiple inputs in a single request. Simple Mode can infer the appropriate creation/editing workflow from the request.

Core categories: Simple Mode, Custom Mode, Styles, Lyrics, Exclude, References, audio uploads, image/video inputs, Voices, Custom Models, Suno Sounds, My Taste and inspiration workflows.

03 / CONTROL SURFACES

Current v6 supports plain-language editing of part of an existing song, single-lyric updates, mashups and sample/isolate/build workflows.

  • Extend: continue from a selected point.
  • Cover: create a new interpretation while retaining source identity.
  • Replace Section: regenerate a selected portion while preserving the surrounding song.
  • Crop: remove unwanted material where supported.
  • Adjust Speed: change speed where exposed by the current interface.
  • Use Styles and Lyrics: reuse creative material in Remix/Edit workflows.
  • Single-lyric editing: change a lyric without rebuilding the whole song when available.
  • Mashup: combine elements from multiple sources with natural-language direction.
  • Sample / Isolate / Build: isolate a useful musical element and build new material around it.

04 / SONG EDITOR

The Song Editor is the targeted section-level editing environment. Use it when the song is mostly right and only a section, lyric, transition or ending needs work.

  1. Select or highlight the section.
  2. Use Replace for a local rewrite or performance change.
  3. Use Edit Lyrics when the words are the problem.
  4. Use Extend when the song needs continuation.
  5. Use section controls to split, crop, move or adjust sections where available.
  6. Use fades for cleaner starts and endings.
  7. Preview alternates before committing and preserve the original for comparison.

The older 2025 editor documentation describes Quick Replace, section movement, fades and section creation. Those details are useful historical context, but screenshots and labels from that article should not be assumed to match the current v6 interface exactly.

05 / REMASTER

Use Remaster when the composition is already useful and the main goal is a new sonic presentation. Compare against the original before committing to the remastered version.

06 / STEMS

Current stem tooling is more granular than the old two-stem workflow.

  • Get Stems: available from Library/Workspace for Pro and Premier.
  • Auto Split: up to 12 stems; Pro/Premier and credit-priced per extraction.
  • Split from Mix: isolate a chosen instrument or vocal plus a complement track.
  • Advanced Split: Premier-only, with a much larger instrument selection.
  • Studio: right-click an audio clip and use Split Stems to create aligned tracks.

Recent community reports describe artifacts and quality loss in some stemming and remix workflows. Treat extracted stems as production material that must be auditioned, not as perfect separation.

07 / SUNO STUDIO 2.0

Studio 2.0 is a full production environment, not just a song editor. It is currently available to Premier subscribers. Suno recommends current Google Chrome for best performance. Studio requires a desktop, laptop or tablet with at least 768px screen width; mobile devices are not supported. Web MIDI is not currently available on Safari.

Workspace

  • Chat Bar: natural-language control for generating audio/MIDI, designing plugins, arranging and making project changes.
  • Transport: Play, Pause, Loop, Follow Playhead, Metronome, clock, tempo and time signature controls are above the timeline.
  • Take Lanes: each generation provides two versions; audition, rate and promote the preferred take without destroying the source.
  • Automation: automate volume, pan and plugin parameters; MIDI Learn works with compatible controllers.
  • Effects: Compressor, Convolution, Delay, Distortion, EQ, Gate and Reverb are built in.
  • Custom plugins: describe an effect in Chat and Studio can build a project/library plugin.
  • MIDI: piano roll, musical typing, external MIDI, quantization, velocity, pitch bend and modulation.
  • Wavetable synth: built-in playable synth with oscillators, filters, envelopes, LFO and modulation.
  • Audio ↔ MIDI: audio can be transcribed into MIDI and MIDI can be used in generative audio workflows.
  • Advanced stems: split audio directly from the timeline.

File workflow

Studio accepts WAV, MP3 and MIDI uploads. Existing Suno songs can be opened from Library using More Actions → Edit → Open in Studio. Exports include the full song, selected range or multitrack output, and individual stems can be downloaded as WAV. Studio does not support conventional VST or Audio Units plugins and does not provide direct DAW synchronization.

Recommended production workflow

  1. Open the strongest existing generation.
  2. Preserve a clean baseline.
  3. Use Take Lanes for non-destructive comparison.
  4. Use section replacement for localized generative changes.
  5. Use stems when the arrangement is right but a part needs independent processing.
  6. Use MIDI for note-level control.
  7. Use effects and automation for mix shaping.
  8. Check generated timing against the metronome.
  9. Export only after arrangement and mix approval.

08 / STUDIO 1.X DEPRECATION

Studio 2.0 replaced much of the old Studio 1.x navigation. Take Lanes replaced the older alternate-lane presentation. Studio 1.x was scheduled for deprecation around early September 2026. Older projects can be opened in 2.0, but 2.0-only effects, automation, MIDI and synth work do not round-trip back into Studio 1.x.

09 / COMMUNITY EVIDENCE

Recent r/SunoAI discussions are useful for identifying issues worth testing, but they are not authoritative product documentation. September 2026 discussions contain both positive v6 reports and complaints about vocal controllability, repetition, Remix/Cover behavior and stem quality. These conflicting reports should be treated as observations to reproduce, not universal properties of v6.

10 / RETIRED OR EXPERIMENTAL INFORMATION

  • Do not present v5.5, v5, v4.5 or older models as selectable current generation models.
  • Do not present undocumented bracket tags, punctuation tricks, fake filenames, gibberish or symbols as official commands.
  • Do not present Studio 1.x screenshots/navigation as the current Studio interface.
  • Do not describe the old basic two-stem workflow as the full current stem system.
  • Do not claim v6 prompting is deterministic.
  • Do not treat one Reddit experiment as proof of a hidden feature or guaranteed control.

11 / EVIDENCE STANDARD

A — Official: current Suno documentation. B — Repeated: independent community observations. C — Reproducible: controlled repeatable testing. D — Hypothesis: plausible but unverified. E — Experimental: deliberately exploratory behavior.

When official documentation conflicts with an old screenshot, tutorial or Reddit post, use the official documentation as the product baseline. When community reports disagree, preserve the disagreement and test it.
