PHASE 8 / EXPERIMENTAL METHOD

CONTROLLED EXPERIMENTATION

Turn “this seems to work” into evidence: freeze the conditions, change one variable, generate multiple samples, compare outcomes and record failures.

RESEARCHV5 → V6 →

01 — THE CORE METHOD

  1. Define one research question.
  2. Freeze model, lyrics, Style, structure, settings and reference.
  3. Choose one independent variable.
  4. Generate enough samples to see whether the effect repeats.
  5. Compare the control and test using the same criteria.
  6. Log successes and failures.
  7. Repeat before upgrading a claim.

02 — CONTROL VS TEST

CONTROL
same model
same lyrics
same Style
same structure
same settings
same reference

TEST
change ONE variable only

COMPARE
vocal / melody / rhythm / arrangement / mix / adherence / failure modes

If two or three variables change at once, the result can still be interesting, but it is no longer a clean single-variable experiment.

04 — SAMPLE SIZE

There is no universal magic number of generations. For a quick screen, use several control/test pairs. For a stronger claim, repeat on more than one song or lyric context. The more variable the generation system, the weaker a one-generation conclusion becomes.

05 — RANDOMIZATION

When practical, avoid judging every control first and every test second. Alternate conditions or randomize their order so fatigue and expectation do not become hidden variables.

07 — RESEARCH VARIABLES

Good single-variable experiments include:

  • one word in a lyric
  • one line break
  • one punctuation pattern
  • one structure cue
  • one Style descriptor
  • one instrument role
  • one vocal delivery cue
  • one exclusion
  • one slider
  • one reference source
  • one model variant
  • one section-edit instruction

08 — MODEL COMPARISON

CONTROL: V6
DISCOVERY: V6-WILD
FAST ITERATION: V6-MINI

Keep the prompt and lyrics constant.
Change only the model.
Record adherence, novelty, consistency and failures.

Suno officially positions v6 around control and precision, v6-wild around experimentation and unpredictability, and v6-mini around faster iteration. That makes the three-model comparison useful as a deliberately controlled branch rather than treating the variants as interchangeable.

09 — SLIDER SWEEP

Do not change Weirdness, Variety, Style Influence and Audio Influence simultaneously if the research question is about one setting. Freeze three and vary one. Record the exact setting values with every generation.

10 — PROMPT DENSITY TEST

A — MINIMAL
primary identity + one defining instrument

B — MODERATE
identity + groove + instruments + vocal

C — DENSE
identity + groove + instruments + vocal + arc + mix + exclusions

Score whether added information improves adherence or merely increases instruction conflict. “More detailed” is a test condition, not a conclusion.

11 — LYRIC GEOMETRY TEST

CONTROL
I still hear your name

TEST
I still hear
your name

Keep every other condition fixed. Compare phrasing, timing, melodic segmentation and vocal emphasis. Then repeat with a different lyric before making a broader claim.

12 — STRUCTURE-TAG TEST

A
[Chorus]

B
[Chorus — full voice, sustained hook]

Compare the same lyric with the two structures. Undocumented descriptive tags remain experimental soft conditioning.

13 — SYMBOL / GIBBERISH TEST

CONTROL
clean Style prompt

TEST
same Style prompt + ⟟⌁✦⌬⌁✦

TEST 2
same Style prompt + glitch_matrix.exe

Do not infer meaning from the token itself. The research question is simply whether the output distribution changes under repeated controlled conditions.

14 — REFERENCE-AUDIO TEST

A — text only
B — text + reference A
C — text + reference B

Use the same song idea and compare what the reference changes. Do not change the prompt at the same time.

15 — LOCAL REPAIR TEST

If a song is mostly successful but one section fails, compare a full regeneration against a local edit/replace workflow. Current V6 officially supports plain-language section editing and single-lyric updates, making local repair a legitimate research branch.

16 — FAILURE-FIRST RESEARCH

Record negative outcomes with the same care as successes:

  • ignored cue
  • wrong vocal
  • genre drift
  • unwanted choir/doubles
  • instrument disappearance
  • late-song degradation
  • unexpected loudness change
  • muddiness or harshness
  • stuttering or artifacts
  • bad ending

17 — CONFIDENCE SCALE

  • LOW: one or two interesting observations.
  • MEDIUM: repeated under the same conditions or across related tests.
  • HIGH: repeatedly reproduced across multiple contexts with controlled comparisons.

18 — EVIDENCE LABELS

  • A — Official: Suno documents the capability or behavior.
  • B — Community: repeated reports with useful detail, but unofficial.
  • C — Reproducible experiment: directly tested and repeatable under stated conditions.
  • D — Hypothesis: plausible explanation without sufficient testing.
  • E — Experimental: intentionally weird or exploratory result.

19 — THE RESEARCH SENTENCE

Every strong finding should be expressible as: “Under these conditions, changing X produced Y in N tests, while Z remained constant.”

20 — PHASE 8 RULE

Change one variable → generate multiple samples → compare → repeat → record the failures. A spectacular one-off is a discovery candidate. A repeatable effect is evidence. A documented feature is official.
