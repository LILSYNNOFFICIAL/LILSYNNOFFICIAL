V5 → V6 TRANSLATION

01 — THE TRANSLATION RULE

V5/V4.5 techniques are historical inputs, not automatic V6 instructions. Preserve the musical intention first, then translate the mechanism into current V6 language and test it. Suno now identifies v6 as the flagship model, v6-wild as the experimental branch and v6-mini as the faster variant. Older-model prompting should therefore be treated as legacy evidence rather than a current guarantee.

03 — STYLE TRANSLATION

LEGACY
synthpop, dark, emotional, huge, cinematic, female vocal, retro, powerful

V6 TRANSLATION
Dark synthpop identity, nocturnal midtempo pulse, warm analog bass and glassy synth arpeggios, intimate low-mid lead vocal, verses restrained and sparse, pre-chorus gradually widens, chorus opens into a dense cinematic lift with controlled vocal intensity, clean stereo separation and focused low end, restrained emotional progression

The translation is not “more words.” It converts adjectives into observable musical behavior. Current community V6 research similarly emphasizes prioritized specificity and producer-style briefs, while explicitly remaining unofficial.

05 — VOCAL RANGE TRANSLATION

A useful community hypothesis is to define the singer's overall range in Style and describe the register journey in Lyrics. This is not an official octave-control API. Test relative movement instead of assuming an exact octave instruction is deterministic.

STYLE:
wide vocal tessitura, low-mid verses, upper mixed chorus, highest sustained peaks reserved for final chorus

LYRICS:
[Verse — low-mid, conversational]
...
[Pre-Chorus — rising register]
...
[Chorus — high mixed register]
...
[Final Chorus — highest vocal peak]

06 — WHAT NOT TO PORT BLINDLY

  • Exact slider recipes from an older model.
  • Claims that a particular bracket token always triggers one behavior.
  • Assumptions that more adjectives always increase control.
  • Old model-specific failure fixes applied without a current baseline.
  • Exact octave, BPM, key or arrangement promises from a text cue.
  • Community claims that were never replicated.

08 — PHASE 7 RULE

Preserve intent → translate behavior → isolate variables → compare against a V6 baseline → replicate. Legacy knowledge earns a place in the current guide when the underlying musical idea survives the model transition, not merely because the old prompt looks familiar.
