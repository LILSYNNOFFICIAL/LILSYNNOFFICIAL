HOW THIS LAB WORKS

Control one variable. Preserve the conditions. Generate multiple samples. Record failures. Repeat across songs or model branches. Only then promote a result.

Evidence levels: A official Suno documentation; B repeated community observation; C independently reproducible controlled result; D plausible hypothesis; E novel/experimental observation. An experiment without actual generations remains UNTESTED.

Phase 12 infrastructure is complete; generation evidence is intentionally not fabricated. Product facts may be documented from current official sources, while prompt-behavior findings require actual controlled runs.

01 — STYLE HIERARCHY VS TAG PILE

Question: Does a prioritized producer-style brief produce more controllable results than a flat pile of genre and adjective tags?

CONTROL: dark electropop, emotional, female vocal, synthpop, cinematic, dramatic, energetic

TEST: Identity → groove → instrument roles → vocal behavior → arrangement arc → mix relationships → short exclusions

Hold lyrics, model and settings constant. Score identity, groove, vocal behavior, arrangement adherence, mix relationships and failure count across multiple generations.

02 — LYRICS VS STYLE VOCAL CONTROL

Question: Which vocal properties are more stable when specified globally in Style versus locally in Lyrics?

CONTROL: vocal character only in Style
TEST A: move register/performance direction into Lyrics
TEST B: keep global identity in Style and local delivery cues in Lyrics

Score register, timbre, articulation, intensity, phrasing and consistency. Do not assume a cue is causal until replicated.

03 — STRUCTURE-TAG SPECIFICITY

Compare bare structure labels with progressively richer section directions.

A: [Chorus]
B: [Chorus — huge, emotional]
C: [Chorus — huge emotional lift; full drums; wide guitars; layered harmony; sustained hook]

Measure section timing, arrangement change, vocal delivery and unintended instruction conflicts.

04 — SYMBOL PAYLOAD

Test symbols as an experimental input, not secret syntax.

A: no symbols
B: ⟟ ⌁ ✦ ⟐ ◇
C: ⟟⟟⟟ ⌁⌁⌁ ✦✦✦ ⟐⟐⟐
D: !!! ??? /// ::: ### @@@

Change only the symbol payload. Repeat across several prompts. Log whether outputs differ and whether the difference survives replication.

05 — GIBBERISH / FAKE FILENAME

Probe whether arbitrary lexical shapes correlate with output changes.

glitch_matrix.exe
umbrella_milkshake2.dll
NEON_PROTOCOL::SLEEP_MODE
/usr/local/ghost_mode

Never claim the model has a hidden executable parser. The result is only interesting if the same intervention repeatedly produces a measurable change.

06 — V6 VS V6-WILD VS V6-MINI

Use identical creative inputs and compare the three current V6 branches. Current official guidance positions V6 as the default control model, V6-WILD as the less predictable experimental branch, and V6-MINI as the faster variant.

TEST 01 — V6
TEST 02 — V6-WILD
TEST 03 — V6-MINI

Score prompt adherence, vocal identity, phrasing, arrangement, instrumentation, dynamics, mix clarity, surprise value, usable sections and failure modes.

07 — AUDIO REFERENCE CONTRIBUTION

Compare a text-only creation with an audio-informed workflow while freezing everything else possible.

Measure timing feel, articulation, timbre relationships, performance texture, arrangement influence and unintended carryover. Reference-driven creation is a separate variable from prompt wording.

08 — EDIT / REPLACE VS REGENERATION

Take a mostly successful song containing one controlled failure. Compare local repair with full regeneration.

CONTROL: regenerate the complete song
TEST: edit/replace only the failed section
RECORD: preserved material, repaired material, new artifacts, consistency

The research question is whether local intervention preserves more of the successful generation while changing less unrelated material.

09 — REMASTER BOUNDARY

Test when remastering improves an existing result and when the underlying arrangement/performance problem remains.

Log whether the intervention changes tonal balance, dynamics, clarity, stereo presentation or artifacts without confusing a mix change with a composition change. Current Suno documentation positions Remaster as a refinement workflow with Subtle, Normal and High variation strength.

10 — CHORUS REPRODUCIBILITY

Hold Style constant and vary one lyric-geometry property at a time: syllable density, line length, punctuation, repetition or section cue.

Generate multiple samples and compare the chorus melody, phrasing, register, hook persistence and arrangement. A repeatable effect is stronger evidence than one perfect chorus.

11 — PROMPT-DENSITY THRESHOLD

A = genre only
B = genre + instrumentation
C = genre + instrumentation + performance + arrangement + mix
D = dense producer brief + constraints

Measure whether additional specificity improves adherence or instead introduces competing instructions, generic output or failures.

12 — CONTRADICTION HIERARCHY

intimate close vocal + huge distant arena vocal
sparse arrangement + maximal wall of sound
dry vocal + cavernous reverb
restrained performance + explosive delivery

Contradictions are useful probes of instruction priority. Do not convert one generation into a universal hierarchy; repeat the conflict under controlled conditions.

FAILURE CORPUS

Record failures with the same discipline as successes: buried vocal, wrong vocal texture, chorus arriving early, disappearing instruments, genre drift, late-song degradation, excessive reverb, weak low end, clipped ending, repeated-phrase corruption, ignored section direction, timing drift or other reproducible defects.

A failure is useful evidence only when its conditions are preserved. Save the exact prompt, model, settings, source/reference and intervention.

RESEARCH RULE

Never manufacture a finding. If the site does not contain a real generation result, the experiment stays UNTESTED. If a result appears once, it remains a hypothesis. If it survives controlled repetition and competing explanations, it can become evidence.
