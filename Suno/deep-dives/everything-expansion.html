Migration rule

Never assume a V5/V5.5 tutorial is a V6 manual. Recreate the old prompt, keep lyrics/model/sliders fixed, generate multiple trials, record the change, and keep only techniques that survive V6 testing.

Simple vs Custom

Simple Mode is natural-language direction. Custom Mode separates lyrics, Style, structure, controlled experiments and slider settings. A strong Custom workflow is: lyrics → Style identity → section cues → controls → two candidates → score → change one variable → repeat.

05–07 · Style, Vocal & Lyric Engineering

Style engineering

Describe audible behavior rather than generic praise. High-value dimensions include genre, subgenre, era, vocal type, delivery, tempo/groove, drums, bass, harmony, instrumentation, density, dynamics, texture, spatial character, mix priorities and emotional trajectory.

Dark electropop, intimate low-register male vocal, restrained verses, rising pre-choruses, huge melodic chorus, punchy electronic drums, controlled sub bass, warm analog synth pads, bright arpeggiator accents, stacked chorus harmonies, dry close vocal, wide chorus image, restrained reverb, clean low-mid separation, emotionally devastating but controlled.

Vocal engineering

Specify register, texture, delivery, distance, emotional intensity, harmony, phrasing and density. Fix vocal identity before polishing effects: vocal type → register → delivery → emotion → harmony → spatial character.

intimate husky low-register male vocal with restrained conversational delivery

Lyric engineering

Useful structure labels include Intro, Verse, Pre-Chorus, Chorus, Post-Chorus, Bridge, Breakdown, Build, Drop, Instrumental, Solo, Final Chorus and Outro. Treat tags as guidance, not deterministic code.

[Verse 1 | intimate vocal | sparse drums | restrained delivery]

A strong chorus needs a central hook, repeatable phrasing, melodic emphasis, increased energy and enough space for the hook. A bridge creates contrast through harmony, instrumentation, rhythm, perspective, intensity, density, texture or lyrical revelation.

08–10 · Weirdness, Style Influence, Audio Influence, Variety & Max Mode
WeirdnessSafe → Chaos
Style InfluenceLoose → Strong
Audio InfluenceLow → High
Variety0 = Tight
Max ModeConsistency

Weirdness moves away from expected interpretations. Style Influence determines how strongly supplied style identity remains dominant. Audio Influence appears with audio-reference workflows. Variety changes/updates style prompts to introduce more output variety; when maximum adherence to supplied Style is desired, use 0.

Controlled-testing rule: never change Weirdness, Style Influence and Audio Influence simultaneously while diagnosing a problem. You lose causal information.

Max Mode

Use Max Mode when the task benefits from extra generation effort — especially longer songs, covers where staying close matters, style transfer and vocal/style consistency across longer generations. Do not spend the extra credits on every throwaway experiment.

11–20 · Multimodal References, Audio Uploads, Voices, Custom Models, Sounds, Sampling, Mashup & Extend

References

Supported reference workflows can use Suno songs, playlists, audio uploads, images and video. Give every reference a role instead of throwing unrelated material into one request.

Reference A → vocal character Reference B → drum groove Reference C → synth texture Reference D → emotional atmosphere

Audio uploads

Use the cleanest source available. Trim irrelevant silence, avoid clipping, identify the important section and decide whether you want rhythm, melody, timbre, performance or overall vibe preserved. Compare low, medium and high Audio Influence while holding everything else constant.

Voices

Record in a quiet environment, avoid room echo and clipping, pronounce clearly during verification, and use only voices you have the right to use. Voice/model compatibility can change, so current product documentation outranks old tutorials.

Custom Models

Current documentation describes Pro/Premier Custom Models trained from at least six owned songs. A coherent dataset — same identity, production philosophy, vocal identity and genre family — is more useful than a random collection.

Sounds / Sampling / Mashup

Sounds can provide one-shots, loops, effects, samples and textures. For sampling, identify the useful moment, isolate it, define the new context and then generate. For mashups, explicitly assign roles: vocals, drums, guitar texture, harmonic atmosphere, etc.

Extend

Continue into a larger final chorus with expanded harmonies, additional percussion and a stronger emotional lift, then resolve into a short atmospheric outro.

What this section diagnoses

Preservation vs reinterpretation

The critical distinction is whether the task is to preserve the performance or merely preserve the musical idea. A source can be musically recognizable while the vocal timbre, phrasing, timing or emotional execution has changed.

Rescue decision tree

BAD FULL SONG? ↓ Identify what is actually wrong ├─ One lyric → single lyric edit ├─ One section → Replace Section ├─ Ending → Crop / Extend ├─ Voice → Voice / Add Vocals workflow ├─ One instrument → stems / Studio ├─ Mix issue → Studio effects ├─ Baked effects → Get Dry └─ Overall polish → Remaster

Audio-reference testing

Run a baseline and then vary only Audio Influence. Record model, lyrics, Style, Weirdness, Style Influence, Audio Influence, Variety, Max Mode, references, source and generation date. A/B results instead of trusting one lucky generation.

30–38 · Crop, Reuse, Song Editor, Single-Lyric Edits, Replace, Add Vocals, Remaster & Stems

Crop

Remove unwanted intros, endings, accidental sections or excess silence before rebuilding.

Reuse Prompt

Preserve the setup and change one variable. Example: keep Style, lyrics and controls identical while moving Weirdness from 40 to 55.

Natural-language editing

Keep the verse, instrumentation and vocal performance unchanged. Replace only the chorus with a larger melodic chorus featuring stacked harmonies and stronger drums.

Single-lyric editing

Fix one word or line without rebuilding the whole song. This is a core surgical-editing principle.

Replace Section

FULL SONG ↓ identify defective section ↓ replace only that section ↓ compare transition ↓ keep strongest result

Replacement requests should specify SECTION, KEEP, CHANGE and TARGET.

Add Vocals

Use when the instrumental is already strong and the missing element is the vocal layer. Inspect timing and phrasing afterward.

Remaster

Compare vocal clarity, transients, low-end control, harshness, stereo image, balance, emotional character and artifacts. Do not decide a remaster is better merely because it is louder.

Advanced stems

Current advanced separation includes Auto Split, Split from Mix and Advanced Split. Use stems when one element is defective but the overall generation is strong.

39–47 · Studio 2.0, Chat, MIDI, Synth, Effects, Automation, Recording, Takes & Export

Studio 2.0

Studio is the browser production environment. Current documentation recommends Chrome; desktop, laptop or tablet workflows require at least 768px screen width. Safari does not support Web MIDI in Studio.

Studio Chat

Create an 8-bar warm analog synth bass line at the project's tempo. Keep it sparse during the verse and leave space for the kick and lead vocal.

MIDI

Studio supports MIDI import/recording, piano-roll editing, quantization, velocity, pitch bend, modulation, musical typing, chord mode, arpeggiator and compatible external MIDI hardware.

MIDI = instructions for notes Audio = recorded/generated sound

Audio → MIDI

Transcribe an audio riff to notes, inspect pitch/rhythm, edit, then change the instrument or develop the part further.

Wavetable synth

Useful vocabulary: oscillator, wavetable position, filter, resonance, envelope, attack, decay, sustain, release, LFO, modulation, unison, detune, stereo width and saturation.

Effects

Current built-in effects include Compressor, EQ, Reverb, Convolution, Delay, Distortion and Gate. Studio also supports sidechain compression and custom Studio plugins; conventional VST/AU plugins are not the Studio format.

SOURCE ↓ EQ ↓ COMPRESSOR ↓ DISTORTION / SATURATION ↓ DELAY ↓ REVERB

Automation / Recording / Take Lanes

Automation makes parameters evolve over time. Recording supports compatible audio/MIDI input. Take Lanes let you compare alternate generated versions; score hook, vocal, timing, arrangement, emotion, artifacts and transitions.

Export

Prefer WAV for archival work and multitrack/stems when further mixing is planned. Keep the original project and create the final delivery master separately.

48–57 · Production Vocabulary, Mix/Master Prompting, Repeatability, Testing & Genre Cookbook

Prompt for character, not impossible measurements

Clean controlled low end, vocal-forward mix, punchy kick, defined snare transient, restrained reverb, wide but stable chorus, smooth highs, preserved dynamic contrast.

Do not assume phrases such as exact LUFS, true peak or compressor ratios will force exact measurements. Measure and correct exact engineering targets inside production tools.

Repeatability

Suno is generative. Identical instructions do not guarantee identical audio. Keep model, source, lyrics, Style, sliders, references and editing path fixed when consistency matters.

Scientific testing

A = baseline B = one change C = same change repeated If B improves and C also improves → confidence increases.

Never promote a one-off lucky generation into a guaranteed technique.

Production vocabulary

Transient = initial attack. Dynamics = loudness/energy change. Stereo width = perceived left/right spread. Low-mid buildup = muddy lower-mid energy. Saturation = harmonic coloration. Compression = dynamic control. Sidechain = one signal controlling another. Reverb = acoustic space. Delay = repetition. Gate = threshold-based reduction. EQ = frequency-selective control. LUFS = loudness measurement; prompt text does not guarantee exact LUFS.

58–62 · Downloads, Credits, Commercial Rights, Compatibility & Evidence

Credits / downloads

Current documentation describes plan-specific download limits and V6 generation credit behavior. Treat current Suno documentation as the source of truth because plan limits and product rules can change.

Commercial rights

Do not conflate: Suno's stated rights to generated output ≠ permission to use someone else's copyrighted input ≠ ownership of every underlying idea ≠ guaranteed copyright protection in every jurisdiction.

Before release, verify the plan used, eligibility for commercial use, uploaded-audio rights, Custom Model training rights, voice rights, samples/references and remix/cover permissions.

63 · Master Troubleshooting & The Complete V6 Workflow
DEFINE THE SONG'S PURPOSE ↓ DEFINE GENRE / EMOTION / VOCAL IDENTITY ↓ WRITE / REFINE LYRICS ↓ BUILD STYLE ↓ CHOOSE v6 / v6-wild / v6-mini ↓ SET CONTROLS ↓ GENERATE MULTIPLE CANDIDATES ↓ SCORE ↓ CROP / EXTEND / REPLACE SURGICALLY ↓ REMASTER / STEMS ↓ STUDIO ↓ MIDI / SYNTH / EFFECTS / AUTOMATION ↓ QC ↓ EXPORT + ARCHIVE SETTINGS

Failure-mode rules

  • Prompt soup → reduce conflicting genres.
  • Contradictory instructions → choose a clear priority.
  • Adjective overload → describe audible behavior.
  • Trying to solve a mix in lyrics → move to Studio.
  • Changing everything at once → use one-variable testing.
  • Overusing Max Mode → reserve it for tasks that benefit.
  • Trusting one generation → compare candidates.

Master rescue decision tree

RESULT IS BAD │ ├─ Entire song wrong? → revise Style / vocal identity / model ├─ One section wrong? → Replace Section ├─ One word wrong? → Single lyric edit ├─ Ending wrong? → Crop / Extend ├─ One instrument wrong? → Stems / Studio ├─ Too much reverb/delay? → Get Dry / Studio effects ├─ Mix balance wrong? → EQ / compression / effects / automation ├─ Need different instrument, same notes? → MIDI └─ Need final polish? → Remaster → Studio → external DAW if needed

Core principle: preserve good information. Use the smallest layer capable of fixing the actual defect.
