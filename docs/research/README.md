# Suno Research Corpus

This directory contains the evidence corpus used to update the LIL SYNN `/Suno` guide.

- `suno-v6-evidence-matrix.md` — Phase 2 claims, evidence levels, and integration conclusions.
- `phase2-source-index.md` — source inventory for official Suno documentation and current community research.

The corpus intentionally preserves contradictory community reports. A disagreement is useful research data: it tells us a claim needs controlled testing instead of being promoted to a universal rule.
